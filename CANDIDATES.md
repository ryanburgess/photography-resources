# Resources to consider

These are research suggestions, not Ryan's personal recommendations. Move an entry into the README only after reviewing it, and replace the description with what you found useful.

Source pages reviewed October 7, 2026. This checks the descriptions against the publishers' pages; it does not mean the courses or tools have been personally tested.

## Courses

- [Strobist: Lighting 101](https://strobist.blogspot.com/2006/03/lighting-101.html) — A free introduction to off-camera flash, starting with equipment and light control. Assumes basic familiarity with aperture and shutter speed.

## Articles

- [Cambridge in Colour: Photography Tutorials](https://www.cambridgeincolour.com/tutorials.htm) — Visual explanations of exposure, lenses, editing, color management, and printing. Pick individual tutorials that answer questions you return to.

## Tools

- [PhotoPills](https://www.photopills.com/) — A photography planning app with tools for planning sun, moon, and Milky Way photographs. Review whether it fits your own shooting workflow before adding it.

## Building the first version

Start with the resources you can already explain from experience. A small list with specific notes gives readers a reason to trust your selections.

For each resource, capture:

- Its name and direct link.
- What you learned or what problem it helps solve.
- Whether you still return to it.
- Whether access requires payment or a subscription.

Keep the README organized by format, matching the engineering manager list. If a section gets long, add topic subheadings such as composition, lighting, editing, or printing inside that section.
